# KOREA RE:READ — Archives Expansion (v1.1)

기존 MVP를 그대로 유지하면서 1901년 『The Korea Review』에서 검증한 기록 4건을 새로 추가한 총 6건 버전입니다.

## 추가된 기록
- The Korean Pronoun — 1901년 2월, 인쇄면 p.53
- Xylographic Art in Korea — 1901년 3월, 인쇄면 p.97
- The Seoul Water-works — 1901년 9월, 인쇄면 p.385
- The Status of Woman in Korea — 1901년 12월, 인쇄면 p.529

## 검증 출처
https://anthony.sogang.ac.kr/KoreaReviewFulltextVolume1.pdf
https://anthony.sogang.ac.kr/KoreaReview/index.html
원문 발췌는 공개 교정 OCR 자료와 대조했습니다. 영어 원문은 부분 인용이며 전체 원문은 연결된 출처에서 확인합니다. 한국어 번역·요약·주석은 연구팀을 위한 시연용 설명으로, AI 실험 결과가 아닙니다. 실제 스캔본과의 수작업 대조 및 서지·이용 조건 확인은 추가 검증 과제입니다.

## 주석 데이터 주의
주석은 브라우저의 localStorage에만 저장됩니다. 동일 URL에서 재배포하고 브라우저 저장소를 유지하면 기존 주석이 남지만, 다른 도메인·브라우저로 자동 이전되지 않습니다. 중요 주석은 먼저 JSON으로 내보내세요.
